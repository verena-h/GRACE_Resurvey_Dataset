# GRACE_Resurvey_Dataset
The dataset of the GRACE resurvey, which is available on GBIF.

In CSV.files you can find the data that is available on GBIF as CSV files.
occur_GRACE_2026-11-10.csv also includes "Total Shrub Cover", "Bare Ground", "Bryophytes species", "Droppings", "Lichens species", "Litter", "Rocks" and "Total Herbaceous Cover". Those terms are missing in the occurrence file uploaded to GBIF.

Resurvey_Metadata.csv includes additional metadata of the resurvey plots, which can not be found on GBIF.
